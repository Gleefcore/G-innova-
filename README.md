# Site G-INNOVA

Site vitrine statique, responsive et compatible avec GitHub Pages.

## Structure

- `index.html` : accueil allégé et présentation des quatre offres ;
- `services.html` : prestations détaillées et formulaire de commande ;
- `realisations.html` : aperçu des créations graphiques ;
- `a-propos.html` : fondateur, qualifications et méthode ;
- `styles.css` : identité visuelle et animations ;
- `script.js` : menu mobile, animations et préparation des commandes ;
- `media/` : images optimisées au format WebP.

## Mise à jour sur GitHub Pages

1. Décompresser l'archive du site.
2. Ouvrir le dépôt `Gleefcore/G-innova-`.
3. Téléverser le contenu du dossier décompressé à la racine du dépôt.
4. Confirmer le remplacement des fichiers existants et valider les changements.
5. Vérifier dans **Settings > Pages** que la source est la branche `main`, dossier racine `/`.

Ne pas téléverser uniquement l'archive ZIP : GitHub Pages ne la décompresse pas automatiquement.
